# Applied Data Analytics Project Suite

Selected hands-on labs from the **IBM Data Analyst Professional Certificate** [🔗 Show Credentials](https://www.coursera.org/account/accomplishments/specialization/2DYILKZNE639).

### Objectives

This repository simulates real-world data analytics scenarios, focusing on applied execution across the full analytics lifecycle - from data collection and preprocessing to exploratory analysis, model development, visualization, and dashboard creation.

### Tools & Technologies Used

Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly, Dash, SQL, Excel, Web Scraping (BeautifulSoup), IBM Cognos Analytics, Google Looker Studio

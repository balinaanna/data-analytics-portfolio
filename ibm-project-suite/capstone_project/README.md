# IBM Data Analyst Capstone Project

Projects demonstrate a complete real-world data workflow - from raw data acquisition to insight generation.

## Skills Practiced

- Collected and wrangled data from multiple sources
- Cleaned, transformed, and analyzed datasets using Python (Pandas)
- Performed exploratory data analysis to identify patterns and trends
- Built clear data visualizations
- Created interactive dashboards using BI tools (Looker Studio, IBM Cognos Analytics)
- Communicated insights to support data-driven decisions

## Tools & Technologies

Python, Pandas, Matplotlib, Seaborn, Beautiful Soup, Looker Studio

# Data Analysis with Python

Projects focus on structured data analysis workflows using Python, and cover the full analytical process - from importing raw datasets to developing and refining predictive models.

## Skills Practiced

- data ingestion & wrangling
- data cleaning & preprocessing (missing values, normalization)
- exploratory data analysis (EDA) - descriptive statistics, correlation analysis, visualization
- predictivemodeling - simple, multiple, polynomial, ridge regression
- model evaluation & tuning - pipelines, train/test splits, cross-validation, GridSearchCV
- performance metrics - R^2, MSE

## Tools & Technologies

Python, Pandas, NumPy, SciPy, Matplotlib, Seaborn, scikit-learn
